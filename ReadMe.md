# Smart task Tracker
A web application buit with Flask and Python for managing everyday tasks, tracking completion progress, and organizing deadlines.

## Feautures
- Task creation with category and optional end date
- Interactive completion status and progress tracking
- Task deletion and quick status updates
- AI-assisted subtask suggestions for task breakdown

## Setup Instructions
1. Clone the repository

1. Clone the repository:
git clone https://github.com/your-username/smart-task-tracker.git

2. Install dependencies:
pip install -r requirements.txt

3. Set up environment variables in a .env file:
SECRET_KEY=your_secret_key
GROQ_API_KEY=your_groq_api_key

4. Run the application:
python app.py
